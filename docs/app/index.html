LEGACY MACHINE RESCUE

Browser version: disk inventory and recovery runbook
Read this first. This page reads the disk image and writes the runbook. It does not boot the image: the emulator boot test needs the command-line tool (python -m legacyrescue disk.img --boot), which is in the code repository. An emulator boot would also not prove the real motion card, dongle, serial/DNC link or CNC controller works.

Pick a disk image (raw floppy or hard-disk image, fixed VHD, up to 64 MB), or run the built-in synthetic sample. Your file stays in your browser. Nothing is uploaded.
