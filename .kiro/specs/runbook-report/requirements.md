# Requirements: runbook and report

1. THE SYSTEM SHALL write a runbook with: evidence table, risks, ordered recovery steps, disk inventory.
2. THE SYSTEM SHALL include the image SHA-256 and tell the user to verify any copy against it.
3. THE SYSTEM SHALL always include the line that real hardware compatibility is NOT PROVEN.
4. THE SYSTEM SHALL write a single-file retro CRT HTML report with the real emulator frames embedded.
5. THE SYSTEM SHALL provide a local web app: upload an image, receive the report; uploads are deleted afterwards; 256 MB cap.
